# NEO Tracker Mobile — Лабораторная работа №4

Android-приложение на **Flutter / Dart**: сближения астероидов с Землёй по данным
[NASA NeoWs](https://api.nasa.gov/) и аналитика за последние **7** и **30** дней.

Тема — мобильное развитие проекта из Лаб 3 (настольный NASA NEO Tracker на Python),
переписанное с нуля на другом языке. Подробности — в [REPORT.md](REPORT.md).

## Возможности

| Вкладка | Что делает |
|---|---|
| **Поиск** | Сближения за выбранную дату: число, опасные, ближайшее расстояние, список с диаметром, скоростью и расстоянием |
| **Неделя** | Динамика показателя за 7 дней: график, минимум, максимум, среднее, изменение (абс. и %), тенденция |
| **Месяц** | То же за 30 дней |
| **Настройки** | Свой ключ NASA API (по умолчанию `DEMO_KEY`), размер и очистка кэша |

Показатель на экранах сравнения переключается: **число сближений**, **число опасных**,
**минимальное расстояние промаха** (млн км).

Офлайн: последние полученные данные хранятся на устройстве (SharedPreferences) и переживают
перезапуск. Когда показан кэш — жёлтая плашка «Сохранённые данные, актуальны на ДД.ММ.ГГГГ ЧЧ:ММ»
и причина (нет сети, лимит API и т.д.).

## Требования

- Flutter SDK (stable, 3.27+), Dart 3.5+
- Android SDK (через Android Studio) и телефон с отладкой по USB или эмулятор

## Запуск

```bash
flutter pub get
flutter run                     # на подключённом телефоне / эмуляторе
```

Сборка APK для установки на телефон:

```bash
flutter build apk --release
# файл: build/app/outputs/flutter-apk/app-release.apk
adb install -r build/app/outputs/flutter-apk/app-release.apk   # или скопировать на телефон
```

Если сборка Android ругается на версии Gradle/AGP (зависит от версии Flutter у вас),
пересоздайте обвязку под свою версию — код в `lib/` не затрагивается:

```bash
flutter create --platforms=android --org md.utm --project-name neo_tracker_mobile .
```

После этого проверьте, что в `android/app/src/main/AndroidManifest.xml` есть
`<uses-permission android:name="android.permission.INTERNET"/>` — без него release-APK не выйдет в сеть.

## Тесты

Одна команда:

```bash
flutter test
```

Сеть в тестах не используется (подменяется `MockClient` из `package:http/testing.dart`).

| Файл | Что проверяет |
|---|---|
| `test/feed_parser_test.dart` | разбор ответа NASA: корректный ответ, числа-строки, пропуски → `null`, пустое тело, не-JSON, чужая структура, пустой набор |
| `test/period_stats_test.dart` | минимум, максимум, среднее, изменение абс. и %, рост/падение/без изменений, порог 1 %, старт с нуля, пустой набор |
| `test/validators_test.dart` | дата `ГГГГ-ММ-ДД`, несуществующие даты, диапазон, формат ключа API |
| `test/date_utils_test.dart` | разбиение 30 дней на запросы по 7 дней |
| `test/neo_api_test.dart` | HTTP 401/403/429/500, пустой ответ, нет сети, TLS, тайм-аут, ключ не утекает в текст ошибки |
| `test/neo_repository_test.dart` | кэш после «перезапуска» без сети, частичный сбой периода, битый кэш, остановка после 429 |

## Структура

```text
lib/
├── main.dart                  сборка зависимостей и запуск
├── models/
│   ├── asteroid.dart          одно сближение
│   ├── day_stat.dart          сводка за день (число, опасные, мин. расстояние)
│   └── metric.dart            выбираемый показатель для графиков
├── data/
│   ├── neo_api.dart           HTTP-запрос к /feed, тайм-аут 15 с, коды ошибок → NeoError
│   ├── feed_parser.dart       строгий разбор JSON
│   ├── neo_cache.dart         кэш по дням в SharedPreferences
│   ├── kv_store.dart          интерфейс хранилища (+ память для тестов)
│   ├── neo_repository.dart    «сначала сеть, при сбое — кэш»; месяц = 5 запросов
│   ├── settings.dart          ключ API
│   └── neo_error.dart         единый тип ошибки с понятным текстом
├── logic/
│   ├── period_stats.dart      мин/макс/среднее/изменение/тенденция
│   ├── validators.dart        проверка ввода
│   └── date_utils.dart        даты и разбиение периода
└── ui/
    ├── home_shell.dart        нижняя навигация
    ├── screens/               поиск, неделя/месяц, настройки
    └── widgets/               график (CustomPainter), карточки, плашки
```

## Проверка на защите

1. Открыть «Месяц» с интернетом — данные загрузятся (5 запросов).
2. Включить режим полёта, закрыть приложение и открыть снова.
3. «Неделя» и «Месяц» покажут сохранённые данные и дату актуальности; «Поиск» за сегодня — тоже.
4. Поиск за дату, которой нет в кэше, — сообщение «Нет подключения к интернету» и кнопка «Повторить», без падения.
